# 文笺

无需账号和 API 密钥的文献整理与写作应用。支持文献录入、标签与全文检索、阅读笔记、多篇文章自动保存、正文引用、Markdown 导出及 JSON 备份恢复。

## 启动

需要 Python 3，无第三方依赖。在仓库目录运行：

```sh
python3 server.py
```

用浏览器访问该服务。数据保存在该浏览器、该站点的 localStorage 中；不上传服务器，也不跨设备同步。请定期点击“备份全部数据”。更换访问地址或端口会使用不同的浏览器存储空间。

## 检查

```sh
node --check app.js
python3 -m unittest discover -s tests -v
```

本版本不提供 PDF 解析、文献数据库检索或正式期刊引用格式。引用导出为 Markdown 脚注；文献删除后已有正文引用仍会保留，请自行核对。

## AI 配置

服务端通过 OpenAI 兼容的 Chat Completions 接口生成文献摘要和写作建议。启动前安全设置环境变量：

- `MODEL_BASE_URL`：HTTPS API 基础地址，包含 `/v1` 等服务商要求的路径。
- `MODEL_NAME`：服务商提供的模型名称。
- `MODEL_API_KEY`：服务端密钥，不要提交到 Git 或输入前端。

未配置时，AI 接口返回明确的配置提示，本地整理和写作仍可使用。文本仅在点击 AI 按钮时发送给模型服务；结果需人工核对。AI 结果需点击“插入正文”才会保存到文章。

默认仅监听 `127.0.0.1:8000`。可用 `HOST`、`PORT` 调整。此为无账号的个人开发应用，请勿直接暴露到公共网络；共享部署前应增加身份验证和请求限额。
